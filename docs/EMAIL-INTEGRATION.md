# Transactional email (Resend) — REMOVED (2026-06-03)

Transactional email (Resend / Postmark via `lib/email.ts`) was **removed** from
Peanut Gallery on 2026-06-03. The product collects no email address and sends no
email — there are no accounts and no paid tier.

`lib/email.ts` and `lib/email-templates.ts` were deleted. The prior
implementation is preserved in git history. See
[`legal/PRIVACY-POLICY.md`](legal/PRIVACY-POLICY.md) for the current (no-email,
no-accounts) data posture.
